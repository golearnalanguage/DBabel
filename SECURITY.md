# Security policy

DBabel is a public methodology repository. Do not submit secrets, private infrastructure details, or confidential documents in issues, pull requests, examples, or test fixtures.

Never publish:

- API keys, access tokens, passwords, private keys, or credentials;
- internal service URLs, private hostnames, IP addressing, or non-public endpoints;
- customer documents or customer-identifying material;
- proprietary glossaries or translation memories;
- confidential product roadmaps or internal deployment procedures;
- non-public documentation or licensed content that cannot be redistributed.

For a suspected vulnerability in DBabel's workflow or future executable tooling, use the repository owner's private security-reporting channel when configured. Do not include secrets or confidential source material in a public report.

DBabel's public-search workflow should minimize queries to public terminology information rather than transmitting confidential surrounding text.
