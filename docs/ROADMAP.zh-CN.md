# 路线图

[English](ROADMAP.md) · [文档目录](INDEX.zh-CN.md)

路线图覆盖审核流程、schema、校验器、文档适配和合成回归测试。版本号本身不会创建 Git 标签或 GitHub Release，发布须在验证之后单独执行。

## v1.4：准确性和运行时控制

已实现按需资源路由、上下文与资源计划校验、JSON/CSV 项目术语表及范围内批准规则、双语确定性 QA、按问题选取案例、内容格式探测、能力与后端选择、提取覆盖验证，以及从预检到 QA 和修订检查的衔接。QA 涵盖保护标记、占位符、URL、路径、文件名、命令与环境标记、版本、数值单位和批准术语。

## v1.5：审核工作台

已实现本地双语人工审核、`.dbreview` 会话契约、建议与人工决定分离、便携版决策导入导出、导出检查、DOCX 原件哈希及锚点校验、写入副本与回读验证，以及仅审核和原格式输出流程。

当前改进包含中英文界面、文档上传、多语言、术语上传和评分、六种结果格式、可解释建议、响应式面板、恢复原有品牌资源、DOCX/TXT/MD 原格式交付、双语对照和 Markdown/JSON Agent 交接。DOCX 写入保留非文本 XML 字节；本地启动器和成对语言手册支持离线审校。这些工作树变化在完成验证和正式发布前不构成新版本发布。

后续继续完善对齐、原格式适配和语义复核集成。当前 Agent 交接只生成材料，本身不调用模型。

## 后续适配与协作

- TBX 术语交换、TMX 翻译记忆和保留行内代码的 XLIFF 适配。
- 带往返保真测试的格式专用解析与写入器。
- 更完整的表格、图示、UI 和嵌入对象对齐。
- 带来源和失效规则的本地证据缓存。
- 浏览器资料检索、团队术语批准、项目证据与决定历史。
- 只使用可再分发或合成数据的可复用基准语料。

新增适配器须记录来源和产品范围，分离建议与人工决定，并验证原格式输出。
