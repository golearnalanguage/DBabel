# Research basis

DBabel's design follows established terminology and internationalization principles without redistributing standards text or vendor terminology datasets.

Key public references to consult:

- ISO 704:2022 — Terminology work — Principles and methods: concept/designation-oriented terminology work.
  https://www.iso.org/standard/79077.html
- ISO 30042:2019 — TermBase eXchange (TBX): terminology resource interchange model.
  https://www.iso.org/standard/62510.html
- W3C Internationalization Tag Set (ITS) 2.0 — includes Translate and Terminology data categories.
  https://www.w3.org/TR/its20/
- NIST CSRC Glossary — emphasizes interpreting each term-definition pair in the context of its source publication.
  https://csrc.nist.gov/glossary

Vendor documentation/glossaries should be searched at runtime according to the candidate's vendor/product/version scope; they are not copied into DBabel.
