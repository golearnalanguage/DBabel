# 文档格式

[English](DOCUMENT_FORMATS.md) · [文档目录](INDEX.zh-CN.md)

DBabel 分别记录提取范围、审核结果和原格式交付。上传面板与 `scripts/intake_document.py` 使用同一提取器，`intake.json` 保存格式判断及未提取内容。需要 Python 3.9+，并安装 `requirements-dev.txt` 中的 PyYAML 和 jsonschema。单次上传上限为 16 MiB，Office 解包总量上限为 64 MiB，一次导入最多建立 20,000 个语言与单元组合。

| 输入 | 依赖 | 提取范围 | 原格式交付 |
|---|---|---|---|
| TXT、`.md` Markdown | 标准库 | UTF-8 非空行及原始行号 | 替换已批准行；保留 BOM、各行换行符、空行和未修改字节。修改行中的 Markdown 标记须复核；不允许插入新换行。 |
| DOCX | ZIP/XML | 上传提取正文及表格段落；显式锚点流程可处理受支持的其他文本部件 | 在副本中替换文本节点，保留命名空间、样式、表格、关系、图片和未修改部件。待修改段落若含域、修订、嵌套段落、换行或制表符，需另行处理。 |
| CSV、TSV | `csv` | 非空单元格和表头，带行列位置 | 仅导出审核结果，不重建原表 |
| JSON、JSONL | `json` | 带 JSON Pointer 的字符串值，不含键名、数字及布尔值 | 仅导出审核结果 |
| HTML | `HTMLParser` | 按源码顺序提取 script/style/template 以外的文本 | 仅导出审核结果；不处理属性、CSS 版式及动态 DOM |
| XLSX | 内置 ZIP/XML 提取器 | 已存储的文本单元格，含隐藏工作表；不把纯数字、日期、布尔值或公式送去翻译 | 显式锚点审核会话可把已批准单元格写入新的 XLSX。适配器只修改被批准的工作表单元格 XML，并逐字节校验所有未触及 OOXML 部件的内容；公式单元格绝不回写。被修改单元格内部的富文本 runs 会收敛为批准后的单元格文本，因此仍需目视复核。 |
| PPTX | ZIP/XML | 按幻灯片 XML 顺序提取段落 | 仅导出审核结果；不含备注、图表、SmartArt、母版及图中文字 |
| PDF | 可选 `pypdf` | 按页提取文字层 | 仅导出审核结果；核对阅读顺序和表格，扫描件先做 OCR，不重建 PDF 版式 |
| XML、DOC/XLS/PPT、含宏 Office、ODF、图片 | 格式探测器 | 可识别，尚无内置上传提取器 | 转换副本，或由适用解析器提供带定位单元 |

PDF 提取在同一环境执行 `python -m pip install pypdf`。文本格式可能重叠，例如 TSV 呈现 CSV 特征、Markdown 以 HTML 开头。提取器确认文本内容后再按声明语法解析，同时保存探测结果和实际采用格式。

## 工作副本与双语结果

只上传一个 DOCX、TXT 或 MD 原文且只有一种目标语言时，原文会作为**尚未审核**的当前工作副本。用户或 Agent 需要提供译文，复制原文并不表示已翻译或已批准。有现成译文时，确认对齐后可用译文文件作为版式模板。多语言使用独立审核单元；需要分别输出原格式文件时，应按目标语言各建一个会话。

所有本地会话，包括演示和仅审核会话，都能导出 JSON、CSV、TSV、Markdown、HTML、TXT 快照。每行保留语言、位置、审核与 QA 状态；待审单元沿用当前文本，未接受建议单独保存。JSON 还保留问题、证据、备注和版本。HTML 提供响应式原译文双栏对照。CSV/TSV 对可能被当作公式的单元格添加前置单引号，以文本形式交给电子表格程序。

## 原格式交付包

已建立锚点的受支持会话可导出 **FINAL 最终版** 或 **CHECKPOINT 阶段版**。最终版要求相应审核完成；阶段版应用已批准修改，未审部分保持原样。交付包含原格式文件、`.receipt.json` 回执、`.handoff.json`、`.handoff.md` 交接说明及 `.bilingual.html` 双语对照，浏览器自动下载 ZIP。交接记录列出已改、保持、未纳入的单元，以及人工决定、备注、版本、哈希、QA 和尚未执行的 Agent 复核。已有文件不会被覆盖，浏览器连续导出自动编号。

DOCX 校验对比包内容、非文本 XML、修改目标和未修改文字。XLSX 校验批准单元格回读、ZIP 条目集合、未修改 OOXML 部件内容逐字节一致，以及目标工作表除批准单元格元素外不发生变化。译文长度、字体和打开文件的软件仍会影响换行及分页，交付前需在 Word 或 LibreOffice 检查版面。详见[实现评估](NATIVE_EXPORT_ASSESSMENT.zh-CN.md)和[本地教程](WORKFLOW_GUIDE.zh-CN.md)。
