# 任务能力矩阵

[English](AGENT_CAPABILITY_MATRIX.md) · [文档目录](INDEX.zh-CN.md)

| 任务 | 所需能力 | 缺少时的处理 |
|---|---|---|
| 任务路由 | 读取有效上下文和配置 | 按 SKILL 手工路由，说明未运行机器路由 |
| 格式检查 | 有限范围字节与容器探测 | 扩展名只作为线索 |
| 解析能力检查 | 确认后端与运行时 | 不根据包名推定支持读写 |
| 资料内查询 | 阅读来源和上下文 | 保留未解决术语，获取可读资料 |
| 公开来源核验 | 检索并打开原始页面 | 使用已有证据，缺口标记 REVIEW |
| DOCX/PPTX 审核 | 读取段落、表格、幻灯片及可访问备注 | 明确已检查文本和省略结构 |
| XLSX/XLSM 审核 | 区分文本、公式和宏 | 只检查可读内容，保护可执行内容 |
| HTML/Markdown/结构化文本 | 区分正文、标记、代码和键 | 仅处理明确的可译范围 |
| PDF/图片/UI 审核 | 页面阅读或视觉/OCR | 记录提取缺口和不确定标签 |
| 提取覆盖验证 | 实际后端、结构、缺口和定位 | 不能宣称完整覆盖 |
| 双语审核 | 阅读并对齐两侧单元 | 将未对齐或缺失项列为待审 |
| 术语验证、确定性 QA、schema 校验 | Python 3.9+ 和依赖；双语 QA 还需对齐 | 说明未运行的检查，必要时手工核对 |
| 翻译 | 在术语约束下生成译文 | 提供已解决术语和剩余问题 |
| 修订 | 向副本进行格式感知写入 | 返回带位置建议 |
| 修订验收 | 回读内容、必要时渲染 | 明确缺少的检查 |

格式识别、解析器可用、提取成功与覆盖完整是不同结论。涉及备注、批注、图表、嵌入对象、公式、链接或宏时，应分别记录范围。

## 本地工作台能力

| 功能 | 已实现 | 前提与范围 |
|---|---|---|
| 文档上传 | 文本、结构化文本和 Office 的带位置提取 | 依赖与遗漏见[格式说明](DOCUMENT_FORMATS.zh-CN.md) |
| 原格式输出 | DOCX/TXT/MD 副本、原件哈希、锚点与内容校验、双语和 Agent 交接 | 其他格式需专用写入器，版面另行检查 |
| 阶段输出 | 应用已完成人工决定，记录待审 ID | 待审文本保持原样 |
| 结果快照 | 所有本地会话可导出六种格式 | 明示待审状态 |
| 多语言 | 每种目标语言独立单元 | Agent 或用户提供译文；原格式文件逐语言导出 |
| 术语上传与评分 | 标准 CSV/JSON 验证和词汇检查 | 适用的 PROJECT_APPROVED 条目和明确语言 |
| 人工修改后复核 | 导出文本、备注、版本和哈希 | Agent 需实际执行语义检查 |
| 便携审核 | 离线决策、视图和报告 | 原格式输出前导回本地并重新 QA |
| 界面语言 | 英文和简体中文 | 浏览器保存偏好，正文不自动翻译 |

已完成审核可仍含 REVIEW 发现；已验证修订则需要通过对应的输出检查。按照 SKILL 的任务状态报告真实完成程度。
