# 架构

[English](ARCHITECTURE.md) · [文档目录](INDEX.zh-CN.md)

DBabel 将运行时上下文、术语证据、审核决定和文档交付分开保存。仓库提供流程、schema、策略、模板、适配器与合成测试；项目文档和术语由运行时输入。

```text
用户请求和文件
  → 上下文、格式探测、能力检查、资源路由
  → 按 load_now 读取任务资料，并结合用户资源和官方证据
  → 提取结构、定位、覆盖验证
  → 术语与翻译判断
  → 确定性 QA + 语义与证据核对
  → 人工审核决定
  → Agent 复核建议 → 人工再次确认
  → FINAL / CHECKPOINT 导出检查
  → 原格式副本、回读与结构验证、双语对照和交接记录
```

Accuracy Core 检查字面量完整性和适用的已批准术语。Agent 判断含义与证据，人负责审核决定，导出适配器校验写入副本。项目术语仍是用户数据，只有范围匹配的 `PROJECT_APPROVED` 条目进入确定性检查。

文件探测限定读取范围且不执行文件内容。可选解析器不是必装依赖；解析器可用后还须验证实际提取覆盖。原格式写入仅支持已实现的适配器，DOCX 比较非文本 XML 和其他部件，TXT/MD 保留行结构；渲染版面另行检查。

本地服务器监听 `127.0.0.1`，浏览器通过会话令牌访问。上传副本保存在会话 `inputs/`，人工决定和事件单独记录。便携版在独立 HTML 中保存审阅状态，导回原会话后重新运行本地 QA。
