# API 兼容与恢复

[English](PROVIDER_COMPATIBILITY.md)

按网关实际协议选择：NewAPI 等兼容服务选择 **Chat Completions**，`/responses` 选择 **Responses**，Anthropic 原生接口选择 **Claude Messages**。支持基础地址和完整端点，不重复拼接路径；模型名按网关提供的名称填写。连接测试成功不代表整个文档流程已通过。

公司接口必须先接入公司内网或 VPN。建议先启用流式响应和 300 秒空闲超时。“跟随系统”在内置客户端和 SDK 中均遵循操作系统的代理绕过规则，包括 macOS 代理例外；命中例外时直连，并保留配置的证书信任。“不使用代理”始终直连，“自定义代理”使用填写的代理。可信 HTTP 内网地址沿用显式授权开关，HTTPS 仍校验证书；不限制厂商或模型名单，安装包不含公司地址和密钥。

桌面配置可选择协议、**请求客户端**（自动、内置兼容客户端、官方 SDK）、流式响应、是否省略 temperature、超时（1–600 秒），并填写可选模型参数 JSON。导入的配置也支持 `max_output_tokens` 和 `transport_backend`。例如 `{"thinking":{"type":"disabled"}}` 仅在用户填写时发送，是否支持由网关与模型决定；此处不得填写密钥。推理系列模型默认省略 temperature；400 错误明确拒绝 temperature 或 stream 时，各做一次兼容回退，其他错误正常显示。

支持 JSON 与 SSE 的完整译文解析，包括心跳、多行 data、不同换行、用量与结束标记。思考文本、工具调用不会充当译文；响应截断、乱码、输出 token 耗尽、空闲超时、空答案不会记为完成。缓存大小有上限，流式总时限为 `max(600, timeout_seconds * 6)` 秒。

请求最多尝试三次，退避等待或 Retry-After 最长 60 秒。401、403、402 立即停止。翻译或语义批次中断后拆半，后续沿用较小批次；格式校验失败只针对具体问题重试。成功批次实时保存；续跑可调整超时、流式、代理、temperature 和模型参数，不重做已完成内容。原文、语言、端点、模型和协议身份必须一致；新参数不会重新生成已完成的译文。

## 可选官方 SDK 与任务预检

[requirements-integration.txt](../requirements-integration.txt) 锁定 OpenAI/Anthropic 官方 SDK。配置 `transport_backend` 可选 `auto`（已安装且端点兼容时使用 SDK，否则用标准库）、`stdlib` 或 `sdk`（不可用时明确报错）。SDK 需要 Python 3.10+，核心标准库路径保留 Python 3.9 支持。响应完成、重试上限、检查点与人审规则仍由 DBabel 控制；采用项目和原始许可见[第三方声明](../THIRD_PARTY_NOTICE.md)。

**请求客户端**默认“自动”（`auto`）。测试网关与既有标准库适配时可选“内置兼容”（`stdlib`）；选“官方 SDK”（`sdk`）则要求使用已安装的 SDK。该选择会保存，在配置导入时保留，并传给翻译任务；切换客户端保留同一服务身份，可继续使用匹配的检查点。

Anthropic SDK 适配要求端点以 `/v1/messages` 结尾，其他 Messages 路径在 `auto` 模式下使用标准库传输。SDK 自身重试关闭，由 DBabel 控制重试上限。扩展模型参数保持在 JSON 请求正文内，无法覆盖 SDK 的传输请求头或超时设置。

SDK 请求发送 `Accept-Encoding: identity`，遇到压缩响应会在解码前拒绝，响应大小上限也约束 SDK 的错误正文。网关需要遵循 identity 编码；当前 SDK 适配不解压 gzip、Brotli 等编码响应。传输诊断记录 SDK/版本、请求 ID、耗时和接收字节数，并遮蔽配置中的密钥。

```bash
python scripts/check_provider_connection.py --provider-config provider.json --task-check
```

命令发送一个小型合成中英翻译，检查 JSON 单元及受保护标记，返回 `TASK_READY` 或 `CONTRACT_FAILED`，附用量与传输诊断。它会使用服务 token，验证范围是一次小型合同；整份文档的质量与吞吐还需实际运行。连接可用、格式预检、提取成功、实际覆盖和最终导出分别检查。

桌面**测试翻译能力**按钮执行同一任务预检。结果区分可用的翻译合同与已经连通但返回格式不符的端点，并显示具体校验问题供修正。

## 错误说明与处理

连接测试和翻译失败页显示错误类型与标题、原因说明、建议操作和可用的服务错误原文；HTTP 状态码作为补充信息。诊断还会显示可用的请求 ID、尝试次数、请求客户端和网络路由。服务原文有长度上限，配置中的密钥会遮蔽；服务未提供原文或请求 ID 时省略相关项。修正后续跑会保留已成功保存的批次。

| 错误 | 含义与处理步骤 |
|---|---|
| 认证失败（`401`） | 服务拒绝令牌。检查该网关签发的用户令牌、有效期和已保存的服务地址；请求立即停止。 |
| 余额或权限问题（`402` / `403`） | 检查网关余额、令牌权限及所选模型/渠道的访问权限；这些状态立即停止。 |
| 端点或模型不存在（`404`） | 对照网关配置，核对协议、接口路径和准确的模型 ID。 |
| 速率或额度限制（`429`） | 根据服务原文区分限流和额度耗尽，按提示等待或补充额度后续跑。 |
| 服务或网关暂不可用（`500` / `502` / `503` / `504`） | 服务、网关或中间代理返回失败。访问内网端点时，先检查 VPN、DNS 和记录的路由，对照系统代理例外或获准的直连路径；确认已到达服务且仍失败时，向服务管理员提供请求 ID，检查上游渠道和容量。`503` 的传输尝试最多三次。 |
| 网络、TLS 或超时 | 检查连接、内网 DNS、VPN 和代理；TLS 错误还需检查证书信任链。空闲超时需核对流式支持，并在允许范围内调整超时。 |
| 响应不完整或契约校验失败 | 查看具体截断、JSON、单元 ID 或技术字面量校验问题，运行能力测试并核对网关支持的参数；失败内容不会记为已完成批次。 |

状态码需要结合服务原文、请求 ID 和实际路由使用，才能判断响应来自哪个环节并选择处理步骤。

## 便携审核

Portable HTML 不依赖网络或 API 账户，浏览器本地缓存审核决定、当前位置及未完成译文/备注，并绑定会话与原始单元内容，输入不符不会恢复。清理浏览器、隐私模式或存储失败会影响缓存。**保存进度**下载包含决策和未完成编辑的恢复 JSON；**恢复进度**只允许恢复到匹配的会话。**导出 decisions.json** 仍用于本地工作台决策交换，未确认编辑只恢复到编辑框，不视为批准译文。将决策导入对应完整本地工作台后重新 QA，才能做原格式交付；原格式导出和 AI 聊天仍属于完整本地工作台。
