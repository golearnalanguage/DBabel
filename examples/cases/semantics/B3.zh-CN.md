# B3 数值相同，单位、默认值与作用范围已经变了

[English](B3.md)

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** BILINGUAL_REVIEW。
**输入：** 参数表及注释：

| 参数 | 默认值 | 单位 | 作用范围 | 特殊值 |
|---|---:|---|---|---|
| retry_wait | 500 | ms | 每次重试 | 0 表示不等待 |

待审译文：“The connection timeout is 500 seconds. A value of 0 disables retries.”

**问题成因：** 参数名与相邻连接设置混淆；表头单位在抽取时丢失；“不等待”被扩写成“取消重试”。

**排查与判断：**

1. 将同一行的数值、单位、范围和特殊值重新绑定，不能只抽取 500。
2. 区分等待间隔、连接超时、总重试时长；不能因位置相邻就认作同一指标。
3. 把默认值与固定上限分开；把 0 的特殊语义与功能开关分开。
4. 若允许改写单位，需证明换算正确并留痕；参数值本身不能随正文换算自动修改。

**处置：** `REPLACE` 为“The default wait per retry is 500 ms. A value of 0 means no wait.” 另对参数名 `PROTECT`。若源表与注释给出不同单位，先 `REVIEW`，查适用版本的参数定义。

**验收：** 值、单位、默认属性、每次范围及 0 的含义全部一致；数字相等不能单独判定通过。

下一步：回到当前片段核实上下文和证据，记录定位、建议和未决项；有授权才修订，修订后重新 QA。

## 扩展：规格参数应便于扫读

合成原文：“服务器（物理机或虚拟机）1 台；建议 CPU 插槽数不超过 2。”

对于查阅型规格栏，可建议：`Servers (physical or virtual): 1; CPU sockets (recommended): ≤ 2.`
若原文已分成两行，就分别保留在原来的行或单元格中。若要求保留排版且原文只有一个段落，则使用分号串联，不擅自新增表格、项目符号或换行。

这一问题归类为**规格信息的可扫读表达**，对应 `SCANNABLE_SPECIFICATION_PRESENTATION`。核对六项绑定：对象、数值、单位、比较关系、约束强度和适用范围。不能把“1 台”扩写为“至少 1 台”，不能把“建议”写成 must，也不能把 CPU sockets 换成 cores。原文对磁盘吞吐量附有随机写、块大小等条件时，要与该数值一起保留。

验收需同时通过文字含义核对和实际版面检查。QA 对符号与文字表达的比较可能报候选问题，应记录解释后复核，不能仅为消除提示而改掉真实含义。两行标签式表达是本案例的设计选择，不是书籍中的逐字规定。依据及查阅范围见[研究依据](../../../docs/RESEARCH_BASIS.zh-CN.md)。
