# B3 Equal numbers can still change units, defaults and scope

[简体中文](B3.zh-CN.md)

Synthetic diagnostic case, not product evidence. Mode: BILINGUAL_REVIEW.

The source parameter table specifies `retry_wait`, default `500`, unit `ms`, scope “per retry”, with `0` meaning no wait. The target says: “The connection timeout is 500 seconds. A value of 0 disables retries.”

Bind the value back to its unit, default, per-retry scope and special-value meaning. Do not confuse a wait interval with connection timeout or the complete retry duration. Unit conversion requires a justified mapping and must not silently change an executable parameter value.

Propose: “The default wait per retry is 500 ms. A value of 0 means no wait.” Protect `retry_wait`. If table and notes conflict, use REVIEW and consult the applicable version's parameter definition. Equal digits alone cannot pass this review.

## Scannable specifications

Synthetic source: “服务器（物理机或虚拟机）1 台；建议 CPU 插槽数不超过 2。”

For a reference specification, propose: “Servers (physical or virtual): 1; CPU sockets (recommended): ≤ 2.” Keep existing separate cells/lines where present; if layout is locked to one paragraph, retain that structure and use a semicolon. Do not add a list, table or break.

Classify this as `SCANNABLE_SPECIFICATION_PRESENTATION`. Check six bindings: object, quantity, unit, comparator, modal force and scope. An exact count of 1 is not “at least 1”; a recommendation is not “must”; sockets are not cores. Preserve block size and workload qualifiers attached to storage-throughput figures.

Verify meaning and actual layout. Explain any QA candidate caused by a symbol/word comparator change; do not alter meaning simply to silence the check.
