# A2 上级标题涵盖两台主机，不等于每一步都执行两次

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** BILINGUAL_REVIEW。
**输入：**

```text
一级标题：配置主机 A 与 B
  二级标题：3.1 通用准备
  范围：在 A、B 分别创建目录。
  二级标题：3.2 主机 A 初始化
  范围：仅在 A 执行。
  步骤：生成实例文件，然后同步到 B。
  随附文件清单：instance/config/、instance/data/、instance/control/
```

待审译文把 3.2 写成“Initialize the instance on both hosts”，并把同步对象概括成“configuration files”。

**问题成因：** 只沿用一级标题的范围；又把目录名误当作内容类型。

**排查与判断：**

1. 将每步绑定到最近明确的执行范围：3.1 为 A、B；3.2 为 A。上级标题提供任务范围，不覆盖更具体的局部限定。
2. 区分“在哪里执行同步命令”和“文件到达哪里”：B 是接收端，不自动成为初始化步骤的执行端。
3. 读取给定文件清单，确认同步对象包含数据与控制文件；不只看路径名称猜测。
4. 在源目标对应中检查执行主机、身份、对象和顺序是否完整保留。

**处置：** “on both hosts”→“on host A only”，`REPLACE`；“configuration files”→“instance files”，`REPLACE`，必要时按原清单列出范围。若没有清单，只保留中性的“files in the specified directory”，对内容性质标 `REVIEW`。这不是部署正确性认证。

**验收：** 没有新增 B 上的初始化步骤；同步路径不变；每处范围修订均有记录。若源文没有“仅在 A”且上下文互相矛盾，不按常见部署经验自行补出答案。
