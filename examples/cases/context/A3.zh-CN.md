# A3 标题、按钮与正文指向不同操作对象

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** AUDIT、SOURCE_RESEARCH。
**输入：**

```text
章节：查询缓存管理
小标题：清理当前会话缓存
按钮：Clear session cache
说明：此操作会删除当前表空间。
```

**问题成因：** 可能误贴其他章节的说明，也可能有未说明的副作用。单词各自正确，组合后却描述了不同对象：缓存与表空间。

**排查与判断：**

1. 抽取“动作—对象—范围”：清理／缓存／当前会话，与删除／表空间／当前对象。
2. 在同一文档搜索完整异常句，判断是否从“存储管理”章节复制；搜索命中只说明可能来源，不证明该句一定应删除。
3. 查同版本该按钮的帮助、操作说明与影响范围；核对按钮属于哪个页面和对象。
4. 分别排除标题错、按钮错、正文错三种可能。资料无法排除时，不直接按多数文本统一。

**处置：** 异常说明标 `REVIEW`，明确问“实际影响是会话缓存还是表空间”。取得同范围直接依据后，才修改错误位置；不为了让句子通顺而悄悄改成“清理缓存”。

**验收：** 报告说清是哪两个操作对象冲突、查过哪里、还缺哪项证据；不执行按钮或删除命令来验证翻译。
