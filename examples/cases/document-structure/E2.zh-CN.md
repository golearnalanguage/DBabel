# E2 合并表头与公式让“空白格”失去含义

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** BILINGUAL_REVIEW。
**输入：** 电子表格 B1:C1 合并为“主节点”，D1:E1 合并为“备节点”；第二行是“单位”“默认值”。译文把 C 列数值划入备节点，并把公式 `=Config!B3` 替换为当前显示值。

**问题成因：** 按单元格逐个抽取，丢失合并表头作用域；把公式结果误当作静态文本。

**排查与判断：**

1. 恢复合并区域和多级列头，将每个值绑定到角色、单位、字段三元组。
2. 空白单元格可能继承上方合并标题，也可能真实为空；仅在结构支持时继承。
3. 分别读取公式和显示值；检查文本改动是否误伤工作表引用、命名范围或数据验证。
4. 批注、隐藏行和嵌入对象只在实际可读取时计入覆盖；不能默认它们不存在。

**处置：** 错误角色归属提出 `REPLACE`；公式 `PROTECT`，已被替换的目标单元格单独记录恢复建议。无法读取的批注或嵌入说明列为缺口，相关判断 `REVIEW`。

**验收：** 表头层级、行列绑定、公式及引用保持正确；数值显示相同不足以证明文件完整。
