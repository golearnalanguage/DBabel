# E3 图中主备角色互换，单词都正确仍然是错译

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** BILINGUAL_REVIEW。
**输入：** 技术演示文稿中，节点 N1 标“主节点”，N2 标“备节点”，箭头从 N1 指向 N2。英文稿的 Primary、Standby 拼写正确，但分别贴在 N2、N1；另一页又复用了本页截图。

**问题成因：** 将标签脱离图形对象翻译；根据左右位置或相似缩略图分配目标页，忽略节点身份与页面差异。

**排查与判断：**

1. 用页码、图形对象、节点 ID 和连线端点建立对应，不仅用“左图／右图”。
2. 核对角色标签、箭头方向、图注所描述的数据流，不能靠英文词表检查代替关系检查。
3. 比较两页源图的独有对象或状态，确认是真实重复还是不同步骤；源页重复本身不一定有错。
4. 检查组合图形、母版文字及文本溢出，防止文字存在却覆盖了相邻标签。

**处置：** 按源图身份提出逐标签的 `REPLACE`；重复错图提出页面对应修正。缺少源图或无法确认节点时标 `REVIEW`，不能按惯例认定左主右备。

**验收：** 角色、节点、连线和页面对应全部一致；实际编辑后必须回看渲染结果。仅提取到 Primary、Standby 两个词不能证明图正确。
