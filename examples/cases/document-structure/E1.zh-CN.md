# E1 PDF 抽取顺序打乱，脚注中的适用条件消失

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** BILINGUAL_REVIEW、AUDIT。
**输入：** 双栏技术手册左栏写“支持在线操作¹”，右栏属于另一节；页脚 ¹ 写“仅适用于指定存储模式”。抽取文本把右栏接到左栏句后，并遗漏页脚。译文因此变成无条件支持在线操作。

**问题成因：** PDF 字符存储顺序不等于阅读顺序；抽取器未覆盖脚注，限定范围随之消失。

**排查与判断：**

1. 对照页面图像恢复栏位、标题边界和脚注锚点；不要把抽取文本直接视为连续正文。
2. 将主句与脚注作为一个语义单元对齐到译文，确认脚注限定的是哪项功能。
3. 区分“只漏翻脚注”“脚注有译文但锚点丢失”“脚注在文件中却未显示”。
4. 看不清脚注时记录位置和缺口，不能自行补成常见限制。

**处置：** 原脚注清楚且任务允许修订时，提出恢复脚注及对应锚点的建议并留痕；无法辨认则 `REVIEW`、coverage=PARTIAL。恢复限定不等于验证产品能力，事实真实性另行界定。

**验收：** 页面阅读顺序、脚注文字与锚点同时复核；只验证正文文本存在，不能判定版式和语义完整。
