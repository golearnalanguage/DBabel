# E4 HTML 属性有些可译，有些承担程序绑定

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** TRANSLATE、BILINGUAL_REVIEW。
**输入：** 任务允许翻译用户可见文字、title 和 aria-label；链接与程序标识符保持原样。

```html
<a id="retry-link" href="#retry-policy"
   title="查看重试规则" aria-label="查看重试规则">重试规则</a>
<span translate="no">EXAMPLE_MODE</span>
```

目标稿把 href 改成 `#重试规则`，遗漏 aria-label，并将 EXAMPLE_MODE 译成自然语言。

**问题成因：** 只看页面可见文字，或反过来把所有属性都视为可翻译文本。

**排查与判断：**

1. 按 DOM 节点和属性角色建立可译边界：正文、辅助说明与功能标识符分别处理。
2. 读取 translate 标记及继承范围，并核对任务是否明确覆盖该标记；本例没有覆盖。
3. 保留 href、id 及其绑定关系；只有用户要求链接本地化且目标映射可验证时，才另行处理。
4. 对照可见文字与无障碍标签，检查其中一处是否遗漏；显示正确不等于所有目标文本已译。

**处置：** 文本、title、aria-label 在授权范围内翻译为一致的 Retry policy 等表达；id、href、EXAMPLE_MODE `PROTECT`。目标稿已破坏的绑定与标识符逐处标注恢复建议。无法确认链接目标或标记含义时 `REVIEW`。

**验收：** DOM 结构、链接锚点和保护字符串保持一致；可译属性未遗漏；没有用正则全局替换修改脚本、样式或标识符。
