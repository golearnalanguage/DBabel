# C1 相同术语在不同产品中对应不同层级

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** LOOKUP、AUDIT。
**输入：** 对比文档附两份已读、适用的产品定义：

| 资料范围 | 给定定义 |
|---|---|
| 产品甲 | schema 在相关创建语句中与 database 表达同一对象 |
| 产品乙 | 一个 database 包含多个 schema；schema 内组织表等对象 |

待审文档把两列 schema 都解释成“独立数据库”，并宣称两种对象可以一一对应迁移。

**问题成因：** 将一个产品中的命名规则当作跨产品通用定义，又将术语近似推成实现等价。

**排查与判断：**

1. 按列绑定产品和版本，禁止给整张表只分配一个产品范围。
2. 比较定义、包含关系、命名空间及访问边界；词形相同不证明层级相同。
3. 将“如何称呼”与“迁移是否一一映射”分开，后者需要额外的对象与迁移规则证据。
4. 检查图例、列标题和脚注是否已有区分，不为统一译词抹掉差异。

**处置：** 产品乙列“独立数据库”的解释 `REPLACE` 为“数据库内组织对象的命名空间”。产品甲列按其给定定义保留。对迁移等价主张 `OUT_OF_SCOPE_CLAIM`；不自动转换建库、建模式语句。

**验收：** 概念关系写出适用范围；不建立无证据的全局 `synonym_of` 映射。只知道两者“用途相近”时，不能升级为等价。
