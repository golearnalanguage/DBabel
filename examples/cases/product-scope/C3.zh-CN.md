# C3 正文项目用语与精确 UI 名称不必相同

合成诊断案例；不得作为实际产品证据。只有人工审核者能批准修改。

**模式：** BILINGUAL_REVIEW。
**输入：** 本次范围明确的三项资料：

- 项目词表：说明性正文中的“目标数据库”使用 target database。
- 同版本英文 UI：对应选项卡名称为 Destination。
- 中文源文：“在‘目标’选项卡中选择目标数据库。”

待审译文：“Select the target database on the Target tab.”

**问题成因：** 全局词表覆盖了精确 UI 名称；同一个汉语词的两次出现实际承担不同角色。

**排查与判断：**

1. 将引号内选项卡名与正文概念分开，分别绑定 UI 记录和词表。
2. 按界面位置、控件功能与版本匹配，不能只在英文截图中搜索一个相似单词。
3. 查清 UI 记录是否实际打开；项目约定不能自动充当厂商界面证据。
4. 若已存在准确译文，保留它，不为了单词一致把两个角色强行统一。

**处置：** Target tab 中的 Target `REPLACE` 为 Destination；target database `KEEP`。未取得 UI 记录时，标签 `REVIEW`，正文仍可按项目词表处理。

**验收：** 译文为“Select the target database on the Destination tab.”；修改只作用于对应控件标签。项目选择不被标记为官方通用名称。
